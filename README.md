<img width="468" height="98" alt="image" src="https://github.com/user-attachments/assets/7bb359ee-45d1-4eae-b762-0e15c691ce20" /># SIT720 8.1D — Sydney Housing Price Prediction & Decision Support System

An end-to-end machine-learning project that predicts Sydney residential sale
prices and serves them through a Streamlit web app, built as a real-estate
decision-support tool.

## Files
| File | Description |
|------|-------------|
| `8_1D_sydney_housing.ipynb` | Full pipeline, Parts 1–6 (executed, with outputs) |
| `app.py` | Streamlit decision-support web app |
| `sydney_housing.csv` | Cleaned dataset — 102 sold properties (Mosman, Blacktown, Parramatta) |
| `part5_comparison_filled.csv` | Part 5 ML vs LLM vs human estimates |
| `part5_comparison_blank.csv` | Part 5 template |
| `cv_results.csv`, `largest_errors.csv` | Model results exported by the notebook |
| `*.png` | Figures generated by the notebook |

## How to run
1. `pip install pandas numpy scikit-learn matplotlib joblib streamlit`
2. Open the notebook and **Restart & Run All** (saves the trained model to `model/`).
3. Launch the app: `streamlit run app.py`

## Results
Best model: Random Forest (cross-validated R² ≈ 0.72). Largest errors come from
prestige/waterfront properties whose value isn't captured by the feature set.
